Electric Vehicle Market Performance & Insights

1. Project Overview

This capstone project analyzes Electric Vehicle (EV) market data using Tableau. It explores manufacturers, annual sales trends, and battery capacity through interactive data visualizations.

2. Project Objectives

- Analyze electric vehicle manufacturers.
- Compare vehicle counts across manufacturers.
- Visualize annual sales by model year.
- Compare average battery capacity.
- Build an interactive Tableau dashboard to communicate insights.

3. Tools and Technologies

- Tableau Cloud
- CSV datasets
- GitHub
- Data visualization and analysis

4. Dataset

The project uses two CSV files:

- Training dataset: Used as the main project dataset.
- Testing dataset: Uploaded to this repository.

The training dataset is retained locally because of its file size.

5. Dashboard Visualizations

The Tableau workbook contains the following visualizations:

1. EV Manufacturers Analysis: Compares vehicle counts across manufacturers.
2. EV Sales by Model Year: Displays annual sales trends.
3. Average Battery Capacity: Compares average battery capacity across manufacturers.
